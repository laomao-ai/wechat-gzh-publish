— 题眼 —

稿子写完只是一半，剩下一半是排版、封面和推送。这一篇把后一半走一遍。

很多人卡在发布这一步：排版要调，封面要裁，粘进后台又要改。

这套流程把这些事情固定下来。你只负责写 Markdown，剩下的按顺序交给它。

01

SECTION 01 / 03

先准备好三样东西


开始之前，确认手边有这三样：

NO.01

一篇 Markdown

标题、摘要写在开头，正文用 ## 分节。

NO.02

公众号凭证

AppID 和 AppSecret，只保存在本机。

NO.03

IP 白名单

把本机出口 IP 加进公众号后台。

✦ 小贴士

白名单要填境内出口 IP

开着代理时，境外查询站看到的是代理节点。用 doctor 命令同时探测两边，按提示填写。

02

SECTION 02 / 03

四步走完一次发布


1

拉取 Skill

放进 Agent 的 skills 目录。

2

配置凭证

交互式输入，不会回显在屏幕上。

3

体检

确认凭证、IP 和网络都通了。

4

推送草稿

排版、裁封面、写入草稿箱，最后自己点发表。

体检只需要一行：




BASH

python3 scripts/wechat_draft.py doctor

改稿不会堆出重复草稿

同一篇稿子，用 front matter 里的 id 记住它对应的草稿。再推一次是更新原稿，不是新建一篇。

03

SECTION 03 / 03

每一步分别检查什么


环节检查什么
排版只用公众号支持的标签和内联样式
封面裁成 900×383，主体不被切掉
推送命中旧草稿就更新，否则新建

划重点

流程固定下来以后，每篇文章只需要操心内容本身。
