# 内容结构与成稿质检

核心原则：**不帮你写，只诊断该怎么写。**

AI 抢笔是这类工作流最大的失败模式——它会把你变成"AI 味"的作者。以下方法全部用于**诊断**，不用于代写。

---

## 零、第一性原理：先问「这篇为什么值得存在」

写之前必须能回答：

1. **读者是谁**，具体到处境（不是"所有人"、"大家"）
2. **他现在卡在哪**（不是"不知道该做什么"）
3. **这篇解决什么**，一句话
4. **凭什么是我说**（亲测/踩坑/数据/独有视角）

任何一条答不上来 → **不要开写**，先想清楚。

> 选题从哪来：不是灵感，是**从已有库存装配**。把 wiki 里的 concepts/sources 交叉，找"两处材料指向同一个未被回答的问题"——那就是选题。

---

## 一、核心主张收敛

**一篇只保留一个核心主张。**

其他观点必须降级为：证据 / 案例 / 解释 / 行动建议。

| 症状 | 诊断 |
|---|---|
| 多个主张并列 | 核心被稀释 |
| 说不清哪个最重要 | 核心不明确 |
| 读者读完不知道记住什么 | 核心不明确 |

**做法**：把全文主张列出来，强行只留 1 个，其余标注它承担什么角色。

---

## 二、五维共鸣诊断（选理论，不靠感觉）

**关键**：一次诊断只选**一个**主理论。只有出现第二个独立机制且原文有明确证据，才加辅助理论。

| 理论 | 查什么 | 典型症状 |
|---|---|---|
| **社会认同与自我分类** | 读者能否认出自己属于这个群体 | 身份对象含混 |
| **框架理论** | 有没有说清问题怎么发生、责任如何形成 | 有结论无推导 |
| **情绪评价理论** | 目标相关性/责任/确定性/控制感是否写出来 | 只有情绪标签 |
| **使用与满足** | 读者看完能用它做什么 | 用途不清 |
| **情绪激活与分享** | 实用性/趣味/新奇/惊奇是否形成分享理由 | 分享理由不足 |

### 五个常见问题模式（可直接当检查表）

**1. 身份对象含混**
症状：频繁使用「大家」「普通人」「创业者」等宽泛称呼。
改法：补充共同处境、群体边界、具体利益。

**2. 框架缺少因果桥梁**
症状：给出结论，没说明问题怎么发生、责任如何形成。
改法：补一条可验证的因果解释。

**3. 只有情绪标签**
症状：直接写「焦虑」「委屈」「愤怒」，没写出目标受阻。
改法：写出形成情绪的**评价路径**——目标 → 受阻 → 责任 → 后果。

**4. 用途不清**
症状：读完不知道这条能用来判断、决策、表达还是收藏。
改法：明确**一个主要用途**。

**5. 分享理由不足**
症状：有观点但缺实用价值/新奇信息/惊奇。
改法：先确认这篇是否真需要传播。**目标是理解或收藏时，不要硬塞传播刺激。**

---

## 三、内容兑现检查（标题承诺 ≠ 正文交付）

**这是最容易崩的一环。**

标题和封面做了承诺，正文必须兑现。兑现不了就**收窄承诺**，不要硬撑。

| 标题承诺 | 正文必须 |
|---|---|
| 「我跑了 7 天」 | 真有 7 天的过程和结果 |
| 「三堵墙」 | 真有三堵墙，不是凑数 |
| 「省了 3000 块」 | 真有这笔账，能算清 |
| 「开源了」 | 真能访问到代码 |

**做不到时的三个选项**：
1. 改标题，收窄到正文能支撑的范围
2. 补正文，最小必要补充
3. 明确标注为「暂定」，等素材齐了再发

---

## 四、标题与正文的一致性

标题里出现的每个事实，**都要能在正文找到落点**。

| 检查 | 说明 |
|---|---|
| 数字一致 | 标题说 7 天，正文不能是"最近几天" |
| 结论一致 | 标题说"回不去了"，正文得真解释为什么 |
| 情绪一致 | 标题焦虑，正文得有对应证据，不能只是标题在喊 |
| 关键词一致 | 标题的核心词，正文得真的围绕它 |

**这条不过，标题就得改。** 宁可标题平淡，不可标题虚。

---

## 五、结构骨架选择

按内容类型选结构，**不要混搭**。

### 问题解决型
```
现象 → 常见误判 → 真实原因 → 解法 → 验证方式 → 适用边界
```

### 复盘型
```
目标 → 实际做法 → 遇到的问题 → 调整 → 结果 → 什么可复用
```

### 方法论型
```
核心主张 → 支撑论证（2-3 个独立依据）→ 反例 → 适用条件 → 不适用条件
```

### 教程型
```
最终效果 → 前置条件 → 步骤（可复现）→ 常见错误 → 验收标准
```

**每个骨架都要有「适用边界」**——不写边界的方法论是伪方法论。

---

## 六、语言洁癖检查

| 规则 | 说明 |
|---|---|
| 删掉「其实」「基本上」「某种程度上」 | 模糊限定词会稀释判断 |
| 数字要有来源 | 「大概 3 倍」不如「实测 2.8 倍」 |
| 不用「非常」「十分」「特别」修饰判断 | 改用具体描述 |
| 同一个概念全文用同一个词 | 换词会让人以为是不同东西 |
| 短句优先于长句 | 一句话讲一件事 |
| 删掉所有「我认为」 | 陈述观点不需要主语背书 |

---

## 七、交付前检查清单

### 事实层
- [ ] 每个数字在正文有依据？
- [ ] 每个「我做了什么」真实做过？
- [ ] 没有虚构的第一人称引语、权威、因果？
- [ ] 没有承诺流量、点击率、效果保证？

### 结构层
- [ ] 核心主张只有一个？
- [ ] 开头说清「这篇解决什么」？
- [ ] 每个小节都在服务核心主张？
- [ ] 有适用边界？

### 一致性层
- [ ] 标题的每个承诺，正文都兑现了？
- [ ] 标题数字 = 正文数字？
- [ ] 情绪强度不超过正文证据？

### 语言层
- [ ] 没有模糊限定词？
- [ ] 同一个概念没换词？
- [ ] 没有「AI 味」句式（排比堆砌、过度总结、空洞收尾）？

### 读者层
- [ ] 开头 200 字能让人知道为什么要读下去？
- [ ] 读完能带走什么？说得清吗？

---

## 八、AI 味自检（最容易翻车的地方）

**五个典型信号**：

1. **过度总结**——每段结尾都是「总之，xxx 很重要」
2. **空洞排比**——「不仅…而且…更是…」
3. **预设读者**——「相信你也曾经…」
4. **空动词**——「进行优化」「实现提升」「发挥作用」
5. **完美收尾**——「让我们一起…」（如果不需要号召就别写）

**处理原则**：**删掉比改写好。** AI 味的根源通常不是措辞，是"什么都想说"，删掉多余的部分，节奏自然就回来了。

---

## 九、质检的边界

**不承诺流量、不预测平台指标、不分析已发布内容为何传播。**

只诊断稿子本身：主张是否清楚、机制是否落实、结构是否支撑、承诺是否兑现、语言是否可信。

实际流量还受选题规模、账号关系、分发机制、竞争环境影响——**这些不在稿子可控范围内，别混为一谈。**
